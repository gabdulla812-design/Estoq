## Этап 2. Инвентаризации и локальное хранение — ГОТОВО

Выбрано хранилище: **SQLite через `sqflite`**. Причина: библиотека активно поддерживается, данные структурированы (инвентаризации и позиции), транзакции снижают риск повреждения данных, а схема хорошо подходит для поиска, редактирования и экспорта. Интернет и регистрация не требуются.

- [x] Создание новой инвентаризации с названием и датой.
- [x] Список ранее созданных инвентаризаций.
- [x] Добавление позиции: штрихкод, необязательное название, количество.
- [x] Повторный штрихкод суммирует количество в пределах одной инвентаризации.
- [x] Редактирование количества/названия.
- [x] Удаление позиции.
- [x] Данные сохраняются после закрытия приложения.
- [x] Полностью автономная работа.

## Этап 3. Сканирование — ГОТОВО

Используется поддерживаемый пакет `mobile_scanner`.

- [x] Сканирование камерой.
- [x] Защита от ложного многократного срабатывания одного кода коротким cooldown.
- [x] Непрерывное сканирование без возврата к карточке после каждого кода.
- [x] Каждый успешный скан сразу добавляет 1 единицу в текущую инвентаризацию.
- [x] Повторный скан того же товарного кода после cooldown увеличивает количество существующей позиции.
- [x] Счётчик сканов за текущую сессию.
- [x] Счётчики позиций и единиц обновляются прямо на экране камеры.
- [x] Вибрация и короткий системный звук при успешном сохранении скана.
- [x] Ручной ввод штрихкода остаётся доступен.
- [x] Понятное сообщение при ошибке/отказе в разрешении камеры.
- [x] GS1 DataMatrix распознаётся как тот же товар, что и EAN-13, когда AI `01` содержит эквивалентный GTIN-14 с ведущим нулём.
- [x] Перед сопоставлением GTIN проверяется контрольная цифра, чтобы не преобразовывать случайные строки.

## Готовность MVP

Версия `0.1.3+4` содержит быстрый непрерывный режим инвентаризации. После зелёной GitHub Actions-проверки требуется практическая проверка на Android: последовательное сканирование нескольких товаров, повторные сканы одного товара, GS1 DataMatrix/EAN-13 и корректность счётчиков без открытия карточки после каждого скана.
